AirTab — Privacy Policy

Official Policy for AirTab Floating Mini Browser • Effective Date: October 21, 2026
100% Offline-First • Zero Remote Code • Zero Data Collection

1. Overview & Privacy Pledge

AirTab is built upon a fundamental principle: your browsing data belongs entirely to you. AirTab operates as an offline-first client extension designed to bring in-page preview capabilities without transmitting data across external servers.

  • Zero Telemetry: We do not track, log, analyze, or collect your search queries, URLs, browsing history, or personal data.
  • Zero External Servers: AirTab has no analytics endpoints, no cloud databases, and no background tracking scripts.
  • No Data Monetization: We never sell, monetize, rent, or transfer user information to third parties or advertising brokers.
  • Client-Side Only: All preferences (such as hotkeys, dark/light theme, pinned state, and local search history) are stored purely on your local machine using Chrome's native storage sandbox.

2. Technical Permissions & Strict Purpose

AirTab requests only the minimal set of Chrome APIs necessary to deliver its core functionality. Here is a clear breakdown of each permission and its exact purpose:

Permission Technical Purpose
declarativeNetRequest & declarativeNetRequestWithHostAccess Required to allow the in-page mini browser to display search results and user-requested link previews by stripping restrictive X-Frame-Options and Content-Security-Policy frame-ancestors response headers exclusively on isolated sub_frame requests.
<all_urls> (Host Permissions) Required because the user can search, enter any web URL, or preview links across any website of their choice inside the in-page floating mini browser.
activeTab & scripting Enables the floating card to calculate bounding coordinates and inject the isolated Shadow DOM popover immediately adjacent to the user's cursor or highlighted text upon user action.
contextMenus Adds convenient "Open Link in AirTab" and "Search in AirTab" items to the right-click menu when users highlight text or right-click on links.
storage Used exclusively on the client-side to save local user preferences (dark/light theme, custom hotkey, pinned window coordinates) via chrome.storage.local.
bookmarks Allows users to quickly search and open their existing Chrome bookmarks from within the AirTab search panel on demand. Bookmarks are read locally and never transmitted.

3. Remote Code Policy & Security Architecture

Zero Remote Code Guarantee: In strict compliance with Chrome Web Store Manifest V3 guidelines, AirTab contains no remote code. It does not use eval(), does not fetch external JavaScript or WebAssembly, and does not load third-party runtime bundles. All code is 100% packaged locally inside the verified extension archive.

4. Third-Party Websites & Embeds

When you preview websites or search queries within AirTab:

  • You are interacting directly with the target web server via standard secure HTTPS iframes.
  • The third-party website's own privacy policy applies to your interaction with their content.
  • AirTab does not modify page content, inject unauthorized ads, or intercept keystrokes or account credentials.

5. User Control & Data Deletion

Because all data is stored on your local device:

  • You can clear your local search history or reset preferences at any time via the AirTab Settings panel.
  • Uninstalling AirTab immediately and permanently deletes all extension-related storage from your device.
